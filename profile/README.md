We make small, sharp tools that cut the strings between your code and the companies
that rent it to you.

### [unrent](https://github.com/stringcutter/unrent)

See which AI services your code depends on, what open source can replace them, and
which models are about to stop working.

```bash
uvx unrent .
```

### How we work

- We show what we find, with file and line, and we measure how accurate we are.
- Your code never leaves your machine.
- Our tools don't tie you in: open source, Apache-2.0, run them yourself.
